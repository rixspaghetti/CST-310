## Overview

This project is designed to explore the fundamentals of OpenGL for 3D rendering. It renders six cubes, each with individual lighting, texturing, and shading techniques applied. The project utilizes the following libraries and technologies:
- **GLAD**: For OpenGL function loading.
- **GLFW**: For window management and input handling.
- **GLM**: For matrix and vector operations in 3D space.

## Project Description: 

This project renders 6 rotating cubes using OpenGL that are able to depict different levels of shininess. It is cross-platform and can be compiled and run on Linux, macOS, and Windows. The project includes a `Makefile` to simplify compilation and execution.

## Features

- **Interactive Window**: Displays 6 rotating cubes.
- **Camera Controls**: The user can navigate around the scene using keyboard and mouse.
- **Lighting Effects**: Specular, diffuse, and ambient lighting applied to the objects.
- **GLFW Integration**: Provides window management and input handling.
- **Cross-Platform Compatibility**: Works on macOS, Linux, and Windows.
